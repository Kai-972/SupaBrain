How it works

Plug it in once. Your AIs do the rest.

01

Connect each AI

Add Supabrain as an MCP server in Claude, Gemini or ChatGPT. Each AI gets an ENS name with its own rules.

// example
"supabrain": {
  "url": "https://supabrain.example/mcp",
  "agent": "lead-claude.demo.eth"
}
02

Work as usual

Your AIs save what they learn and read what the others saved. Every fact records its sources without anyone thinking about it.

●gem-research saved “invoice #0611 due Friday”
●lead-claude read 4 team memories
03

Take a lie back

Mark the source wrong, check the blast radius, revoke. Every AI forgets it at once and payments built on it stop.

●revoke email:acme-0611
●5 memories quarantined, 0 USDC moved
